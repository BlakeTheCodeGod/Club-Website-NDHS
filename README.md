# Coding Club Website

NDHS CODING CLUB WEBSITE

## Files
- `index.html`: page structure
- `style.css`: how it looks
- `script.js`: builds the page from the data
- `data.js`: **the file you edit to add yourself or a meeting**

## Your first contribution
1. Clone the repo and make a branch: `git checkout -b add-your-name`
2. Open `data.js` and add your line to `members`
3. Open `index.html` in your browser to check it works
4. Commit, push, and open a pull request. Someone else reviews it before it merges.

If Git says there's a merge conflict, two people edited the same spot. Keep both lines and delete the conflict markers.

## Publish with GitHub Pages
Repo Settings → Pages → Deploy from a branch → `main` / root. The site appears at `https://<your-org>.github.io/<repo-name>/`.
